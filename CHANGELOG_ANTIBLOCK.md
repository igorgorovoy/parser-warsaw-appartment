# Changelog: Anti-blocking та підтримка проксі

## Зміни від 2025-10-16

### 🎯 Проблема
Otodom блокував запити з помилкою **403 Forbidden** при роботі з серверів (особливо за межами Польщі).

### ✅ Рішення

#### 1. Покращені HTTP заголовки
**Файли:** `base_parser.py`, `otodom_parser.py`

Додано повний набір заголовків для імітації справжнього браузера Chrome:
- `Accept` - підтримка різних типів контенту
- `Accept-Language` - пріоритет польської мови
- `Accept-Encoding` - підтримка стиснення
- `DNT`, `Connection`, `Upgrade-Insecure-Requests`
- `Sec-Fetch-*` - заголовки безпеки Chrome
- `Cache-Control`
- `Referer` - посилання на головну сторінку Otodom

#### 2. Сесії з cookies
**Файл:** `otodom_parser.py`

- Використання `requests.Session()` замість окремих запитів
- Автоматичне відвідування головної сторінки перед пошуком
- Збереження cookies між запитами
- Затримка 2 секунди після ініціалізації сесії

#### 3. Підтримка проксі-серверів
**Файл:** `otodom_parser.py`

- Підтримка змінної оточення `PROXY_URL`
- Автоматичне використання проксі для всіх запитів Otodom
- Формат: `http://host:port` або `http://user:pass@host:port`

#### 4. Документація та інструменти

**Нові файли:**
- `SERVER_SETUP.md` - детальна інструкція для налаштування на сервері
- `test_proxy.py` - скрипт для тестування з'єднання та проксі
- Оновлено `README.md` з секцією про troubleshooting 403 помилок
- Оновлено `env.example` з параметром `PROXY_URL`

### 🔧 Використання

#### Без проксі (для локального запуску)
```bash
# Запуск як завжди
./run.sh
```

#### З проксі (для серверів)
```bash
# Додати в .env
echo "PROXY_URL=http://your-proxy:port" >> .env

# Запустити
./run.sh
```

#### Тестування з'єднання
```bash
# Перевірка без проксі та з проксі
python3 test_proxy.py
```

### 💡 Рекомендації

1. **Для локального запуску:** Проксі не потрібен
2. **Для серверів за межами Польщі:** Використовуйте проксі
3. **Для стабільної роботи:** Платний проксі (Webshare.io від $2.99/міс)
4. **Для тестування:** Безкоштовні проксі з free-proxy-list.net

### 📝 Технічні деталі

**Стратегія обходу блокування:**
1. Використання сесій з cookies
2. Попереднє відвідування головної сторінки
3. Реалістичні заголовки браузера
4. Підтримка проксі для зміни IP
5. Затримки між запитами (60 сек)

**Чому працює локально, але не на сервері:**
- Датацентрові IP легко виявляються
- Geolocation filtering (блокування за межами Польщі)
- Різні правила антибот захисту для різних регіонів

### 🚀 Наступні кроки (якщо проблеми продовжуються)

1. Збільшити затримку між запитами (до 120-180 сек)
2. Використати rotating proxies
3. Розглянути VPN на сервері
4. Контактувати з адміністрацією для whitelist
