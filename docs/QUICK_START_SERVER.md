# 🚀 Швидкий старт на сервері (Німеччина)

## Проблема
Otodom блокує запити з серверів за межами Польщі (помилка 403 Forbidden).

## ✨ Автоматичний Fallback (НОВА ФУНКЦІЯ)

Парсер тепер **автоматично спробує без проксі**, якщо проксі не працює!

```
⚠️  Проксі не працює: Connection timeout
🔄 Спроба без проксі...
✅ З'єднання без проксі успішне!
```

## Швидке рішення

### Варіант 1: Просто запусти (рекомендовано)

```bash
# 1. Оновити код
git pull

# 2. Запустити парсер
./run.sh

# Парсер автоматично:
# - Спробує з проксі (якщо вказано)
# - Якщо проксі не працює → спробує без проксі
# - Покаже що спрацювало
```

### Варіант 2: Тестування перед запуском

```bash
# Запустити тест
python3 test_proxy.py

# Подивитися що працює і запустити
./run.sh
```

### Варіант 3: Явно вказати проксі (опціонально)

```bash
# 1. Знайти безкоштовний проксі з Польщі
# Відкрити: https://free-proxy-list.net/
# Фільтр: Country = Poland, Https = yes
# Взяти IP:Port (наприклад: 185.217.131.23:8080)

# 2. Додати в .env файл
echo 'PROXY_URL=http://185.217.131.23:8080' >> .env

# 3. Запустити парсер
./run.sh

# Парсер автоматично спробує:
# 1️⃣ Спочатку з проксі
# 2️⃣ Якщо не працює → без проксі
```

## ⚠️ Якщо проксі показує timeout

**Симптом:**
```
Connection to 185.79.243.74 timed out
```

**Причина:** Безкоштовний проксі не працює або занадто повільний.

**Рішення:**
```bash
# Просто закоментуй або видали PROXY_URL з .env:
# PROXY_URL=http://...

# Або:
unset PROXY_URL

# І запусти знову:
./run.sh

# Парсер спробує БЕЗ проксі (може спрацювати!)
```

## Рекомендації для production

**Безкоштовні проксі:**
- ❌ Часто падають
- ❌ Повільні
- ✅ Добре для тестування

**Платні проксі ($2.99/міс):**
- ✅ Стабільні
- ✅ Швидкі
- ✅ З підтримкою
- Рекомендую: [Webshare.io](https://www.webshare.io/)

## Налаштування для cron

```bash
# Додати в crontab
*/30 * * * * cd /path/to/parser && PROXY_URL=http://your-proxy:port ./run.sh >> parser.log 2>&1
```

Або додати `PROXY_URL` в `.env` файл (рекомендовано).

## Діагностика

```bash
# Перевірити IP сервера
curl https://api.ipify.org
# Якщо IP не з Польщі - потрібен проксі

# Тест з'єднання
python3 test_proxy.py

# Переглянути логи
tail -f parser.log
```
