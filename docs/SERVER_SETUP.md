# Налаштування парсера на сервері

## Проблема: геоблокування Otodom

Otodom може блокувати запити з серверів (особливо датацентрових IP) або з-за меж Польщі. Це проявляється як помилка **403 Forbidden**.

## Рішення

### 1. Оновлені заголовки HTTP (вже реалізовано)

Парсер тепер використовує:
- ✅ Повний набір заголовків браузера Chrome
- ✅ Сесії з cookies
- ✅ Попереднє відвідування головної сторінки для отримання cookies
- ✅ Referer заголовок

### 2. Використання проксі-сервера (рекомендовано для серверів)

Якщо ви запускаєте парсер на сервері в Німеччині або іншій країні, рекомендується використовувати польський проксі-сервер.

#### Налаштування проксі

Додайте у файл `.env`:

```bash
# Проксі-сервер (опціонально, для обходу геоблокування)
PROXY_URL=http://your-proxy-server:port

# або з авторизацією:
PROXY_URL=http://username:password@your-proxy-server:port
```

#### Де взяти проксі

**Безкоштовні варіанти:**
- [Free Proxy List](https://free-proxy-list.net/) - фільтруйте по країні "Poland"
- [ProxyScrape](https://proxyscrape.com/free-proxy-list)

**Платні варіанти (надійніші):**
- [Bright Data](https://brightdata.com/) (від $500/міс)
- [Smartproxy](https://smartproxy.com/) (від $75/міс)
- [Oxylabs](https://oxylabs.io/) (від $300/міс)
- [Webshare](https://www.webshare.io/) (від $2.99/міс) - найдешевший

**Рекомендація для тестування:**
1. Спробуйте спочатку без проксі - можливо нові заголовки допоможуть
2. Якщо не працює - використайте безкоштовний проксі з Poland
3. Для постійної роботи - розгляньте платний проксі

### 3. Збільшення затримок між запитами

Якщо проблеми з блокуванням продовжуються, збільште затримку між запитами:

У файлі `base_parser.py`:
```python
# Змініть з 60 на 120-180 секунд
self.request_interval = 120  # 2 хвилини
```

### 4. Альтернативні варіанти

#### A. VPN на сервері
Якщо у вас є доступ до сервера, можна налаштувати VPN з польським IP:
```bash
# Встановлення OpenVPN
sudo apt-get install openvpn

# Підключення до польського VPN сервера
sudo openvpn --config poland.ovpn
```

#### B. Запуск через Docker з проксі
```dockerfile
FROM python:3.11-slim

# Встановлення залежностей
COPY requirements.txt .
RUN pip install -r requirements.txt

# Копіювання коду
COPY . /app
WORKDIR /app

# Налаштування проксі через змінні оточення
ENV PROXY_URL=""

CMD ["python", "multi_parser.py"]
```

#### C. Використання rotating proxies
Для більш надійної роботи можна використовувати сервіси з ротацією IP-адрес:

```python
# У .env файлі
PROXY_URL=http://rotating-proxy-service:port
```

## Тестування

### Локальний тест
```bash
./venv/bin/python multi_parser.py
```

### Тест з сервера
```bash
# Без проксі
python3 multi_parser.py

# З проксі
export PROXY_URL="http://proxy-server:port"
python3 multi_parser.py
```

### Перевірка IP адреси
```bash
# Перевірте, який IP бачить Otodom

```

## Діагностика проблем

### Помилка 403 Forbidden
**Причина:** IP заблокований або виявлено бот  
**Рішення:** 
1. Додайте PROXY_URL у .env
2. Збільште request_interval до 120-180 сек
3. Перевірте, чи cookies зберігаються

### Помилка Timeout
**Причина:** Повільне з'єднання з проксі  
**Рішення:** 
1. Спробуйте інший проксі-сервер
2. Збільште timeout у коді (зараз 30 сек)

### Помилка Connection refused
**Причина:** Проксі-сервер недоступний  
**Рішення:** 
1. Перевірте URL проксі
2. Перевірте, чи проксі активний
3. Спробуйте інший проксі
